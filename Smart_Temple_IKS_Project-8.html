🛕 Digital Indian Temple Knowledge System

Preserving traditional temple knowledge through Computer Science

About the Project

This project combines a physical temple model with a digital knowledge system. The Indian Knowledge Systems (IKS) component focuses on documenting and presenting traditional knowledge associated with Indian temple architecture, spaces, symbolism and practices. Computer Science is used to organize, search and interact with that knowledge.

💻 Computer Science Used

  • HTML: creates the structure of the digital knowledge system.
  • CSS: designs the interface and layout.
  • JavaScript: controls buttons, search, quiz and dynamic information.
  • Data organization: temple knowledge is stored as structured JavaScript data.
  • User interaction: users select topics and receive information instantly.
